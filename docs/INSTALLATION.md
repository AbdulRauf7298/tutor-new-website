# INSTALLATION

## Prerequisites
- Existing WordPress installation
- PHP 8.1+
- MySQL 5.7+ / MariaDB 10.4+
- HTTPS enabled

## Install
1. Copy repository files into WordPress root.
2. Activate theme: `Tutor Custom Theme`.
3. Activate plugin: `Tutor Education Platform`.
4. Configure site timezone and permalinks.
5. Configure SMTP and integration settings.

## Important
- Do not commit `.env` or credential files.
- Use `.env.example` as template only.
