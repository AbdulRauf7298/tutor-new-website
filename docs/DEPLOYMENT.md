# DEPLOYMENT

## Environments
- Staging for validation
- Production for live operations

## Deployment Checklist
1. Backup current production
2. Deploy plugin/theme updates
3. Run database migrations
4. Verify integrations (Google, SMTP, WooCommerce)
5. Verify cron and reminders
6. Smoke test role dashboards and class workflows

## Post-Deployment
- Monitor logs, queue jobs, reminders, and payment mappings
- Keep rollback package ready
